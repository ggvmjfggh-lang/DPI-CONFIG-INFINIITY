# DPI CONFIG INFINITY

Android Device Profile Manager.

## Thông tin dự án

- Tên ứng dụng: DPI CONFIG INFINITY
- Package: com.infinity.dpiconfig
- Phiên bản: 1.0
- Thiết bị tham khảo: OPPO A38
- Hệ điều hành tham khảo: Android 15 / ColorOS 15

## Chức năng hiện tại

- Hiển thị hồ sơ cấu hình thiết bị.
- Hiển thị thông số DPI tham khảo.
- Hiển thị độ nhạy Free Fire tham khảo.
- Hướng dẫn người dùng điều chỉnh thủ công.
- Giao diện tối.

## Lưu ý

Ứng dụng không tự động điều khiển ngắm bắn,
không sửa dữ liệu trò chơi và không bảo đảm headshot.

## Build APK

Dự án sử dụng Android Gradle Plugin 8.6.1
và Android SDK 35.

APK thử nghiệm được tạo thông qua GitHub Actions.
